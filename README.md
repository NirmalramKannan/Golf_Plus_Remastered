The Remastered version of the popular game _Golf Plus_

Installation:

*This project uses Git LFS for large files*

1. Download project

2. Run "git lfs pull" in home directory (Make sure Git LFS is installed: https://git-lfs.github.com)

3. Run "Golf_Plus_Remastered.exe"

4. Enjoy

*I made this game in highschool, so its pretty bad :)
